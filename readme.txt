Tracks post views, likes, dislikes, and provides a modern admin UI for engagement management.

== Description ==
- Tracks views, likes, dislikes for posts
- Modern admin dashboard
- Customizable settings

== Installation ==
1. Upload plugin files to the `/wp-content/plugins/post-engage-manager` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
